# Java Backend và Thymeleaf

Chưa Maven application hoặc Java implementation. Đây là nơi Backend bắt đầu B1.1–B1.3 sau khi Lead duyệt interface/ADR. Không dùng Python business scaffold hay web React legacy.

Code đích: `src/main/java/vn/vietdoc` theo feature; Thymeleaf `src/main/resources/templates`; viewer/editor JavaScript `static`; Flyway `db/migration`; Java tests `src/test/java`. Chỉ tạo folders/files cần cho runnable increment, mỗi working folder có SPEC local.

Đọc [SPEC](SPEC.md), [task/weekly roadmap](../docs/team/backend.md), [architecture](../docs/architecture.md), [target tree](../docs/source-structure.md), [compute protocol](../specs/contracts/compute-api.md). Không có lệnh Maven/start đã verified ở lượt thiết kế này.
