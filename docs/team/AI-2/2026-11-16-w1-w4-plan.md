## Design and constraints

Reuse accepted OCR/preprocess/evidence and existing HTTP admission/correlation/output guards. Keep wire v1, B0 v3 and normalizer v2. Add an in-process source-bound evidence adapter, concrete pipeline, verified release profile and exclusive attempt writer. Avoid a second OCR implementation, queue, DB writes or fixture provider in production. Native model weights are not present under the configured models directory: do not download/provision models without authorization. Fixture runtime tests are separate from actual native acceptance.

Reports use versioned local semantics and independent expectations, never inference-derived gold. Failures are safe codes, with requested/ok/failed/not_run counts. Valid input is never silently omitted.

Artifacts use physical `<attempts_dir>/<job>/<attempt>` and wire `attempts/<job>/<attempt>/...`. Reserve directories without links/reparse points; publish files with exclusive creation/no-replace on Windows/Linux; no multi-file atomic claim. Failed attempts remain unusable and retries need a new attempt ID.
