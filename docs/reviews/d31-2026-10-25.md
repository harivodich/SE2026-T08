## Source and policy

- `src/vietdoc/evaluation/policy.py`: independent versioned canonical scoring
  policy `d31-canonical-nfc-v1-proposed`, not accepted production policy.
- `src/vietdoc/evaluation/scalar_ocr.py`: hash-verified offline loading, ID
  integrity/failure accounting, scalar/critical/per-type metrics, OCR, reports.
- `src/vietdoc/evaluation/__main__.py`: executable CLI, JSON + Markdown output,
  new directory only; `README.md` defines artifact envelope and metric rules.
- `src/vietdoc/evaluation/SPEC.md`: implementation entry points.
- `tests/unit/test_evaluation.py`: 14 tests with hand-computed expected counts,
  including actual CLI and tamper checks. No evaluator-derived expected oracle.
- `tests/fixtures/d31-known-predictions.json`: tiny fictional, hand-edited test
  predictions against existing D1.2 tiny gold. Explicitly not B0/M0 results.

Definitions: EM=TP/present; P=TP/(TP+FP); R=TP/(TP+FN);
F1=2TP/(2TP+FP+FN). Wrong nonempty/invalid value adds FP+FN. Present empty/null/
missing adds FN with separate counters. Absent false fill adds FP; empty absent
adds no TP. Unlabeled/obscured excluded. Denominator 0 gives null. Each metric
includes numerator/denominator/support/exclusions/zero behavior. CER/WER use
corpus Levenshtein edits/reference chars or words on full-page transcripts only.
Unknown IDs reported; duplicate/failed/missing/invalid known IDs remain in E2E
and score as empty predictions. Report pins inputs, versions and evaluator source.
